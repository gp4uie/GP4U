Prescription

Sending a prescription A PDF copy is emailed to admin automatically the moment you issue it, so it can be forwarded to the pharmacy. "Send to Pharmacy" here emails the PDF directly if you have the pharmacy's email address; use "Download PDF" on the issued prescription below if it needs to go out over Healthmail instead (Healthmail doesn't support sending through this app directly). Controlled drugs must still follow HPRA/Medical Council rules.
Medication search is a typing aid, not a formulary The dropdown below is a small starter list of common medications and strengths to save typing — it is not the Irish Medicines Formulary, the BNF, or the HSE reimbursement list, and hasn't been clinically verified. You can still type anything else freely. Edit server/medications.js to add, correct, or remove entries.
